# 数据库操作测试

## 快速开始

### 1. 添加测试页面

在 `app.json` 中添加：
```json
{
  "pages": [
    "pages/test-database/test-database"
  ]
}
```

### 2. 运行测试

1. 在微信开发者工具中打开测试页面
2. 点击"运行所有测试"
3. 查看测试结果

## 测试套件

| 测试套件 | 测试内容 | 覆盖需求 |
|---------|---------|---------|
| 保存报告 | 正常保存、日期验证、必填字段、异常计数 | 3.1-3.5 |
| 报告列表 | 基本查询、分页、字段排除、排序 | 4.1-4.5 |
| 报告详情 | 查询存在/不存在的报告、完整数据 | 5.1-5.4 |
| 指标列表 | 聚合查询、分组、统计、排序 | 6.1-6.5 |
| 指标历史 | 历史查询、过滤、日期范围、数据提取 | 7.1-7.5 |
| 权限验证 | openid 自动添加、数据隔离 | 8.1-8.5 |
| 错误处理 | 网络错误、数据错误、参数错误 | - |

## 前置条件

- ✓ 云开发环境已初始化
- ✓ `reports` 集合已创建
- ✓ 数据库权限规则：`doc._openid == auth.openid`
- ✓ 数据库索引：reportDate (降序)、createdAt (降序)

## 手动验证项

### 权限隔离
1. 使用账号 A 创建报告
2. 使用账号 B 登录
3. 确认账号 B 看不到账号 A 的报告

### 网络错误
1. 关闭网络连接
2. 尝试执行操作
3. 确认显示"网络错误，请重试"

## 注意事项

- 测试会创建真实数据，建议在测试环境运行
- 测试后使用"清空测试数据"按钮清理
- 权限测试需要多个测试账号
- 部分测试必须在真实环境中运行
