# 云数据库配置指南

## 概述

本文档说明如何在微信云开发控制台配置数据库集合、权限规则和索引。

## 1. 创建数据库集合

### 1.1 登录云开发控制台

1. 打开微信开发者工具
2. 点击顶部菜单"云开发"
3. 进入"数据库"管理页面

### 1.2 创建 reports 集合

1. 点击"添加集合"按钮
2. 集合名称：`reports`
3. 点击"确定"创建

### 1.3 创建 users 集合（可选）

1. 点击"添加集合"按钮
2. 集合名称：`users`
3. 点击"确定"创建

**注意：** users 集合是可选的，用于存储用户扩展信息。如果不需要，可以不创建。

## 2. 配置权限规则

### 2.1 配置 reports 集合权限

1. 在数据库管理页面，点击 `reports` 集合
2. 点击"权限设置"标签
3. 选择"自定义安全规则"
4. 输入以下规则：

```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

5. 点击"保存"

**说明：**
- 用户只能读写自己的数据
- `_openid` 由云开发自动添加和验证
- 这确保了数据安全，用户无法访问其他用户的报告

### 2.2 配置 users 集合权限（如果创建了）

1. 在数据库管理页面，点击 `users` 集合
2. 点击"权限设置"标签
3. 选择"自定义安全规则"
4. 输入以下规则：

```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

5. 点击"保存"

## 3. 创建索引

### 3.1 为 reports 集合创建索引

#### 索引 1：reportDate（降序）

1. 在 `reports` 集合页面，点击"索引管理"标签
2. 点击"添加索引"
3. 配置如下：
   - 索引名称：`reportDate_-1`
   - 索引字段：`reportDate`
   - 排序方式：降序（-1）
4. 点击"确定"

#### 索引 2：createdAt（降序）

1. 点击"添加索引"
2. 配置如下：
   - 索引名称：`createdAt_-1`
   - 索引字段：`createdAt`
   - 排序方式：降序（-1）
3. 点击"确定"

#### 索引 3：_openid + reportDate + items 组合索引（推荐）

这个索引用于优化指标历史查询（使用 elemMatch 和日期范围过滤）：

1. 点击云开发控制台提供的"快速创建索引"链接
2. 或手动创建：
   - 索引名称：`_openid_1_reportDate_1_items_1`
   - 第一个字段：`_openid`，排序方式：升序（1）
   - 第二个字段：`reportDate`，排序方式：升序（1）
   - 第三个字段：`items`，排序方式：升序（1）
3. 点击"确定"

**注意：** 创建此索引后，可以删除单独的 `_openid` 索引（如果存在），因为组合索引的前缀可以覆盖单字段查询。

#### 索引 4：_id + _openid 组合索引（可选）

**注意：** 云开发会自动为 `_id` 字段创建唯一索引。这个组合索引通常不是必需的，因为 `_id` 查询已经很快了。

如果需要创建：
1. 点击云开发控制台提供的"快速创建索引"链接
2. 或手动创建：
   - 索引名称：`_id_1__openid_1`
   - 第一个字段：`_id`，排序方式：升序（1）
   - 第二个字段：`_openid`，排序方式：升序（1）
3. 点击"确定"

**索引说明：**
- `reportDate` 索引：用于按日期排序查询报告列表
- `createdAt` 索引：用于按创建时间排序
- `_openid + reportDate + items` 组合索引：用于优化指标历史查询（**推荐创建**）
- `_id + _openid` 组合索引：用于优化按 ID 查询时的权限验证（可选）
- 降序索引可以提高查询性能

## 4. 数据结构示例

### 4.1 reports 集合文档结构

```json
{
  "_id": "report_001",
  "_openid": "oABC123",
  "reportDate": "2024-01-15",
  "itemCount": 3,
  "abnormalCount": 1,
  "items": [
    {
      "name": "白细胞",
      "nameEn": "WBC",
      "value": 5.5,
      "unit": "10^9/L",
      "normalRange": "3.5-9.5",
      "status": "N"
    },
    {
      "name": "红细胞",
      "nameEn": "RBC",
      "value": 3.2,
      "unit": "10^12/L",
      "normalRange": "4.0-5.5",
      "status": "L"
    }
  ],
  "createdAt": "2024-01-15T10:30:00.000Z",
  "updatedAt": "2024-01-15T10:30:00.000Z"
}
```

**字段说明：**
- `_id`: 自动生成的文档 ID
- `_openid`: 自动添加的用户标识，用于权限控制
- `reportDate`: 报告日期（YYYY-MM-DD 格式）
- `itemCount`: 检验项目总数
- `abnormalCount`: 异常项目数（status 为 'L' 或 'H' 的数量）
- `items`: 检验项目数组
  - `name`: 项目中文名称
  - `nameEn`: 项目英文名称
  - `value`: 检验值
  - `unit`: 单位
  - `normalRange`: 正常范围
  - `status`: 状态（'L'=低于正常, 'N'=正常, 'H'=高于正常）
- `createdAt`: 创建时间
- `updatedAt`: 更新时间

### 4.2 users 集合文档结构（可选）

```json
{
  "_id": "user_001",
  "_openid": "oABC123",
  "createdAt": "2024-01-15T10:00:00.000Z",
  "updatedAt": "2024-01-15T10:00:00.000Z"
}
```

**字段说明：**
- `_id`: 自动生成的文档 ID
- `_openid`: 自动添加的用户标识
- `createdAt`: 创建时间
- `updatedAt`: 更新时间
- 可以根据需要添加其他用户信息字段（如昵称、头像等）

## 7. 常见问题

### Q: 为什么需要配置权限规则？

A: 权限规则确保用户只能访问自己的数据，防止数据泄露。云开发会自动验证 `_openid`，无需在代码中手动检查。

### Q: 可以不创建索引吗？

A: 可以，但会影响查询性能。当数据量较大时，没有索引的查询会很慢。建议创建索引。

### Q: 如何查看索引是否生效？

A: 在云开发控制台的"数据库"页面，点击"监控"标签，可以查看查询性能和索引使用情况。

### Q: 数据库是否需要预定义字段？

A: 不需要。云数据库是 schema-free 的，可以动态添加字段。但建议保持数据结构一致，便于维护。

### Q: 如何备份数据？

A: 在云开发控制台的"数据库"页面，点击"导出"按钮，可以导出集合数据为 JSON 或 CSV 格式。
