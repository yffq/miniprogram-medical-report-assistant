# 数据库测试运行指南

## 快速开始

### 1. 前置条件检查

在运行测试前，确保完成以下配置：

#### ✅ 云开发环境
- [ ] 已在 `app.ts` 中初始化云开发
- [ ] 云开发环境 ID 配置正确
- [ ] 能够正常访问云开发服务

#### ✅ 数据库配置
- [ ] 已创建 `reports` 集合
- [ ] 已配置权限规则：`doc._openid == auth.openid`
- [ ] 已创建 `reportDate` 降序索引
- [ ] 已创建 `createdAt` 降序索引

#### ✅ 测试页面配置
- [ ] 已在 `app.json` 中添加测试页面路由
- [ ] 能够在微信开发者工具中访问测试页面

### 2. 运行测试

#### 方式 1：使用测试页面（推荐）

1. 打开微信开发者工具
2. 编译模式选择"数据库测试"（或手动导航到测试页面）
3. 点击"运行所有测试"按钮
4. 等待测试完成（约 10-30 秒）
5. 查看测试结果

#### 方式 2：在代码中调用

```typescript
import { runAllTests } from '../../utils/database.test'

// 在某个页面或函数中
const results = await runAllTests()
console.log('测试结果:', results)
```

### 3. 查看结果

#### 在测试页面中
- 汇总区域显示总体统计
- 每个测试套件显示通过/失败状态
- 点击展开查看详细信息

#### 在控制台中
- 详细的测试日志
- 每个测试用例的执行情况
- 错误信息和堆栈跟踪

## 常见问题排查

### 问题 1：集合不存在

**错误信息：**
```
errCode: -502001
errMsg: collection not found
```

**解决方法：**
1. 进入云开发控制台
2. 创建 `reports` 集合
3. 重新运行测试

---

### 问题 2：权限错误

**错误信息：**
```
errCode: -502005
errMsg: permission denied
```

**解决方法：**
1. 进入云开发控制台
2. 选择 `reports` 集合
3. 点击"权限设置"
4. 配置规则：`doc._openid == auth.openid`
5. 保存并重新运行测试

---

### 问题 3：Query projection 错误

**错误信息：**
```
errCode: -501007
errMsg: [InvalidParameterValue.QueryProjection] Query projection entered in the request is illegal
```

**解决方法：**
1. 检查 `database.ts` 中的 `field()` 调用
2. 确保没有使用 `false` 值
3. 只指定需要的字段（都设为 `true`）
4. 参考 [测试修复说明](./test-fixes.md)

---

### 问题 4：云开发未初始化

**错误信息：**
```
cloud init error
```

**解决方法：**
1. 检查 `app.ts` 中的 `wx.cloud.init()`
2. 确保环境 ID 正确
3. 重启微信开发者工具
4. 重新运行测试

---

### 问题 5：测试数据过多

**现象：** 测试运行很慢，或者查询超时

**解决方法：**
1. 点击"清空测试数据"按钮
2. 等待清空完成
3. 重新运行测试

---

### 问题 6：索引建议

**现象：** 控制台显示索引建议

**说明：** 这不是错误，而是性能优化建议

**处理方法：**
1. 复制"快速创建索引链接"
2. 在浏览器中打开
3. 确认创建索引
4. 参考 [数据库索引指南](./database-indexes.md)

## 性能基准

### 正常性能指标

| 操作 | 预期时间 | 数据量 |
|------|---------|--------|
| 保存报告 | < 500ms | 1 条 |
| 查询列表 | < 300ms | 20 条 |
| 查询详情 | < 200ms | 1 条 |
| 查询指标 | < 1s | 聚合查询 |
| 查询历史 | < 500ms | 10-50 条 |

### 性能优化建议

如果测试运行时间超过预期：

1. **创建推荐的索引**
   - `reportDate` 降序索引
   - `createdAt` 降序索引
   - `_openid + reportDate + items` 组合索引

2. **减少测试数据量**
   - 点击"清空测试数据"
   - 只保留必要的测试数据

3. **检查网络状况**
   - 确保网络连接稳定
   - 尝试切换网络环境

4. **查看云开发监控**
   - 进入云开发控制台
   - 查看"监控"标签
   - 分析慢查询

## 测试数据管理

### 查看测试数据

1. 进入云开发控制台
2. 选择 `reports` 集合
3. 查看数据列表
4. 测试数据的 `reportDate` 通常以 `2024-01-` 开头

### 清空测试数据

#### 方式 1：使用测试页面（推荐）
1. 打开测试页面
2. 点击"清空测试数据"按钮
3. 确认删除
4. 等待完成

#### 方式 2：在云开发控制台
1. 进入云开发控制台
2. 选择 `reports` 集合
3. 选择要删除的记录
4. 点击"删除"

### 备份测试数据

如果需要保留测试数据：

1. 进入云开发控制台
2. 选择 `reports` 集合
3. 点击"导出"
4. 选择导出格式（JSON 或 CSV）
5. 下载文件
